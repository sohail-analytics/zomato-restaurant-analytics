
# Zomato Restaurant Analytics — Global & India Analysis
An end-to-end data analytics project exploring restaurant performance, customer preferences, cuisines, ratings, pricing, and online delivery across global markets and India.

## Project Overview
This project uses Excel, SQL, Tableau, and Power BI to clean, analyze, and visualize Zomato restaurant data. It includes two analysis scopes:
- **Global Analysis:** Restaurant trends across the countries represented in the dataset.
- **India Analysis:** A focused analysis of restaurants and market patterns in India.

## Tools & Technologies
- Microsoft Excel — Data cleaning, PivotTables, PivotCharts, dashboards and slicers
- MySQL — Database management, SQL queries, joins and aggregations
- Tableau — Interactive dashboards and visual analysis
- Power BI — Data modeling, DAX measures and interactive reporting

## Project Methodology
The project followed an end-to-end data analytics workflow:

1. **Data Preparation – Excel**
   - Cleaned and organized restaurant data.
   - Used PivotTables and PivotCharts for analysis.
   - Created Global and India dashboards with interactive slicers.

2. **Database Analysis – MySQL**
   - Imported restaurant data into MySQL.
   - Used SQL queries, joins, filtering and aggregations.
   - Analyzed restaurant distribution and business metrics.

3. **Visual Analytics – Tableau**
   - Developed interactive Global and India dashboards.
   - Created visualizations to explore restaurant performance and market patterns.

4. **Business Intelligence – Power BI**
   - Prepared data using Power Query.
   - Built data models and DAX measures.
   - Developed Global and India interactive reports.
